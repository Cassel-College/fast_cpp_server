类型定义说明

◆ MessageCallback

using MessageCallback = std::function<void(const Message&)>

业务回调函数类型。

派发线程（Dispatcher）在匹配到 Topic 后调用该回调。 回调中禁止执行长时间阻塞操作，避免拖慢派发线程。

枚举类型说明

◆ LifecycleState

enum class LifecycleState
strong

FastMQTT 生命周期状态。

状态迁移： Uninitialized -> Initialized -> Starting -> Running -> Stopping -> Stopped

约束：

  • Initialize 只能调用一次；
  • Start 只能调用一次；
  • Stop 可安全退出所有线程。
枚举值
Uninitialized 

未初始化。

Initialized 

已初始化（已解析配置、创建句柄）。

Starting 

正在启动线程。

Running 

运行中。

Stopping 

正在停止。

Stopped 

已停止。

函数说明

◆ LifecycleStateToString()

const char * LifecycleStateToString ( LifecycleState  s)
inline

将生命周期状态转换为可读字符串（便于日志与健康状态输出）。

引用了 Initialized, Running, Starting, Stopped, Stopping , 以及 Uninitialized.

被这些函数引用 FastMQTT::GetHealthStatus(), FastMQTT::Initialize() , 以及 FastMQTT::Start().
