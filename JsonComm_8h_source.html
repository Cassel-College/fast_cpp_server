3// =============================================================================
4// 文件：JsonComm.h
5// 模块：my_comm / mqtt / json
6// 说明：把 FastMQTT 订阅接入系统的 JSON 协议桥接模块。
7//
8// 设计定位（对照 mqtt/2536pb）：
9// - FastMQTT 只负责 MQTT 字节传输；
10// - 2536pb 负责 protobuf（CS-Y2536）协议接入；
11// - 本模块 JsonComm 负责“订阅主题 + 解析 JSON 报文 + 打印/分发”。
12//
13// 当前版本能力：
14// 1. 订阅配置中的主题，收到消息后用 nlohmann::json 解析；
15// 2. 打印统一格式的中文日志；
16// 3. 提供 RegisterParsedCallback 扩展点，把解析后的 JSON 交给业务模块；
17// 4. 不负责启动 FastMQTT，要求调用方提前把 FastMQTT 拉起来（IsReady）。
18//
19// 强制对外接口（由需求指定，必须存在）：
20// - static JsonComm& GetInstance(); 单例入口
21// - bool Init(...); 初始化
22// - bool Start(); 启动订阅
23// - nlohmann::json Status() const; 状态查询
24// =============================================================================
