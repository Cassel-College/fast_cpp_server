详细描述

气体检测仪 Modbus-RTU 轮询单例。

典型使用方式：

nlohmann::json config = {
{"enabled", true},
{"device", "/dev/ttyUSB0"},
{"baud_rate", 9600},
{"addresses", "1-6"}
};
std::string error;
auto& poll = my_gas_detector_poll::GasDetectorPoll::GetInstance();
poll.Init(config, &error);
poll.Start();
nlohmann::json status = poll.Status();
poll.Stop();
my_gas_detector_poll::GasDetectorPoll::GetInstance
static GasDetectorPoll & GetInstance()
获取进程内唯一的气体检测仪轮询实例。
Definition MyGasDetectorPoll.cpp:16

Init() 成功后只完成配置解析和串口打开，Start() 才创建工作线程。 Stop() 会通知线程退出、等待线程结束并关闭串口，因此析构时不会 遗留后台线程或占用设备文件。

◆ Init()

bool Init ( const nlohmann::json &  config,
std::string *  err = 0 
)

解析配置并打开串口。

参数
config轮询配置 JSON。
err可选错误输出；成功时清空，失败时写入中文原因。
返回
配置和串口都准备成功返回 true；否则返回 false。

重复 Init() 会先安全停止旧的工作线程，再关闭旧串口并应用新配置。 配置解析失败时不会影响当前已经运行的实例。
