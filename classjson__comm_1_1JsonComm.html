详细描述

JSON 通信桥接模块（单例）。

使用方式：

  1. 先确保 fast_mqtt::FastMQTT 已 Initialize + Start；
  2. 再调用 JsonComm::GetInstance().Init(...);
  3. 然后 Start()，模块会对配置中的主题执行 RegisterCallback；
  4. 收到 MQTT 字节后先 json::parse，再打印摘要并分发给业务回调。

◆ RegisterParsedCallback()

std::uint64_t RegisterParsedCallback ( const std::string &  topic,
ParsedCallback  callback,
int  qos = 1 
)

注册一个“解析后的 JSON 回调”。

回调会在本模块完成 json::parse 之后被调用；同一个 topic 可注册多个回调。 若模块已经 Start，且该 topic 尚未订阅，则会立即补订阅。

参数
topic订阅主题。
callback业务回调。
qos订阅 QoS。
返回
回调句柄（>0）；返回 0 表示失败（空回调或未初始化）。

引用了 JsonComm::initialized_, JsonComm::mutex_, MYLOG_ERROR, MYLOG_INFO, MYLOG_WARN, JsonComm::next_handle_, JsonComm::running_, JsonComm::SubscribeTopicLocked() , 以及 JsonComm::topic_entries_.
