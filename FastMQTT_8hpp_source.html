3// =============================================================================
4// 文件：FastMQTT.hpp
5// 模块：FastMQTT —— 全系统唯一的 MQTT 通信模块（单例）。
6//
7// 职责：
8// - 与 MQTT Broker 建立连接、断线自动重连；
9// - 消息发送 / 接收；
10// - Topic 回调管理；
11// - 线程安全消息队列（发送队列 + 接收队列）；
12// - 连接状态监控与健康状态统计。
13//
14// 不负责：
15// - protobuf 编解码（由协议层负责）；
16// - 业务逻辑、Topic 内容解释、Controller 调度。
17//
18// 依赖（严格受限）：
19// MyLog、Mosquitto Client Library、BlockingQueue、nlohmann::json。
20// 禁止依赖 HTTP / Controller / 业务模块 / protobuf 业务类型 / 数据库 / UI。
21//
22// 线程模型：四个后台线程
23// 1. ConnectionManager —— IP 连通性监测与状态聚合；
24// 2. Receiver —— MQTT 网络循环，收到消息压入接收队列；
25// 3. Dispatcher —— 消费接收队列，按 Topic 派发业务回调；
26// 4. Sender —— 消费发送队列，统一执行 MQTT Publish。
27// =============================================================================
