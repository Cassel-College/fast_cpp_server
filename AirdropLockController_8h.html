详细描述

空投锁模块 REST API 控制器

对外暴露以下接口：

  • POST /v1/airdrop_lock/init : 初始化空投锁管理器
  • POST /v1/airdrop_lock/duty_cycle : 设置占空比/频率
  • POST /v1/airdrop_lock/open : 打开空投锁
  • POST /v1/airdrop_lock/close : 关闭空投锁
  • GET /v1/airdrop_lock/status : 获取空投锁状态
