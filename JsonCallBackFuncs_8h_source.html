4// 文件：JsonCallBackFuncs.h
5// 模块：my_comm / mqtt / json
6// 说明：JSON 消息回调集合（单例工厂）。
7//
8// 设计目标：
9// - 对外提供“按 topic 获取 fast_mqtt::MessageCallback”的能力；
10// - 内部封装 nlohmann::json 的解析与中文日志打印；
11// - 后续可以在这里为不同 topic 扩展各自的专属处理逻辑，
12// 而完全不需要改动底层 FastMQTT 传输层。
13//
14// 与 2536pb（protobuf）的差异：
15// - 2536pb 的载荷是 protobuf 序列化字节，需要 ParseFromString；
16// - JSON 的载荷是 UTF-8 文本，直接用 nlohmann::json::parse 解析即可，
17// 因此本模块不依赖任何 protobuf 头文件。
18// =============================================================================
