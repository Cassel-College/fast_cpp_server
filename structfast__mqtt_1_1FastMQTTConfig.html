成员函数说明

◆ FromJson()

static FastMQTTConfig FromJson ( const nlohmann::json &  j)
inlinestatic

从 JSON 解析配置。

支持两种输入：

  1. 直接传入 mqtt 节点内容 { "enable":..., "broker":{...}, ... }
  2. 传入包含 "mqtt" 键的顶层对象 { "mqtt": { ... } }
参数
j输入 JSON。
返回
解析后的配置对象。缺失字段使用默认值，保证健壮性。

引用了 BrokerConfig::auto_reconnect, FastMQTTConfig::broker, BrokerConfig::clean_session, BrokerConfig::client_id, BrokerConfig::connect_timeout_ms, FastMQTTConfig::def, FastMQTTConfig::enable, BrokerConfig::host, BrokerConfig::keep_alive, BrokerConfig::password, BrokerConfig::port, DefaultConfig::qos, ThreadConfig::recv_queue_size, DefaultConfig::retain, ThreadConfig::send_queue_size, FastMQTTConfig::thread , 以及 BrokerConfig::username.

被这些函数引用 FastMQTT::Initialize().
